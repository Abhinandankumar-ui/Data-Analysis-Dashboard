 📊 Data Analysis Dashboard

This is a simple **Data Analysis Dashboard** created to understand and visualize customer and transaction data.

 About the Project

This dashboard shows useful information about customers, transactions, balance, spending, gender, age groups, and transaction movement.

 📊 Dashboard Includes

* Total Balance
* Total Customers
* Top 10 Customers by Transactions
* Top 10 Customers by Amount Spent
* Transaction Status
* Gender Distribution
* Age Group Distribution
* Debit and Credit Distribution
* Day-wise Analysis
* Month-wise Analysis

 🎯 Purpose

The main purpose of this project is to practice **data analysis and data visualization** and understand how raw data can be converted into useful information.

🛠️ Skills Used

* Data Cleaning
* Data Analysis
* Data Visualization
* Dashboard Creation
* Basic Business Analysis
